One image summing up the world's news of Sunday 22 November 2026, drawn as a
newspaper front page: the lead story is the Russian missiles that landed in
Poland (NATO: a violation), with COP31 stalling in Antalya, the capture of
cartel boss "El Chapo Isidro" in Sinaloa, Iran's tanker strikes in the Strait
of Hormuz, the FBI criminal-database breach, the factory fire in Cikande,
Banten, and the UN court's genocide ruling against Myanmar — plus Peru's M6.7
quake, Leeds stunning Chelsea 4-1, GTA VI's record $3.79bn launch, and
Amazon's near-$7.5bn Decart deal in the also-today strip. Every headline is
set from the day's reporting; the image is drawn programmatically, so no text
can garble.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` copies `entry.png` (1024x1024, under 1 MiB) to
`$MAKEFUN_OUTPUT_DIR/entry.png`. Deterministic, no network, standard library
only.
